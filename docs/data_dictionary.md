# Platform Data Dictionary & Epistemic Specification

## 1. Architectural Philosophy: Epistemic Provenance

In a hybrid agricultural platform combining deep learning diagnostics, physical Internet-of-Things (IoT) telemetry, external public APIs, and numerical digital twin simulations, data provenance and epistemic integrity are critical.

Treating simulated forecasts or ML inferences as physical ground truth introduces catastrophic model drift, hallucinations, and corrupted agronomic feedback loops.

The platform formalizes all ingested, derived, and simulated records with five canonical epistemic types:

| Epistemic Type | Description | Permitted Sources | Storage Targets |
| :--- | :--- | :--- | :--- |
| **`observed`** | Empirical physical ground truth measured directly on the farm/field. | On-field IoT sensors, soil probes, agronomist field scouting, manual harvest weighing. | `field_observations`, `SoilRecord`, `CropYieldRecord` |
| **`external`** | Authoritative third-party observation data from regional or global providers. | NASA POWER API, ERA5/AgERA5, national weather services, SoilGrids, FAOSTAT. | `data/external/`, `field_observations` (`epistemic_type="external"`), `WeatherRecord` |
| **`predicted`** | Algorithmic estimations output by trained machine learning or statistical models. | ResNet-50 Disease Classifier, Yield Prediction Regressors, Risk Scoring Engines. | `prediction_records`, `DiseasePredictionResponse` |
| **`simulated`** | Synthetic hypothetical what-if runs generated by computational digital twins. | Numerical crop growth models (APSIM/DSSAT), hydrological balance engines. | `twin_scenarios`, `TwinScenarioRecord` |
| **`recommended`** | Prescriptive agronomic guidance or operational advisories. | Expert rule-engines, calibrated decision-support models. | Advisory logs, Actionable recommendation payloads |

## 2. Canonical Data Schemas (`pipelines/common/schema.py`)

All cross-service data pipelines exchange records strictly adhering to Pydantic contracts with explicit lineage metadata:

### 2.1 Base Provenance Fields (`BaseProvenanceRecord`)
- `source_id` (str): Unique hardware identifier, API endpoint, or model version.
- `epistemic_type` (Enum): Must be one of `observed`, `external`, `predicted`, `simulated`, `recommended`.
- `collected_at` (datetime, UTC): Timestamp of acquisition or generation.
- `lineage_version` (str): Schema version identifier (e.g., `"1.0.0"`).
- `metadata` (dict): Extensible dictionary containing operational parameters, checksums, and execution context.

### 2.2 Agroclimatology / Weather Record (`WeatherRecord`)
- `latitude` (float): Bounded $[-90.0, 90.0]$.
- `longitude` (float): Bounded $[-180.0, 180.0]$.
- `record_date` (date): Daily observation timestamp.
- `temperature_c` (float): Mean 2-meter air temperature (°C, bounds: $[-60.0, 60.0]$).
- `precipitation_mm` (float): Corrected daily precipitation (mm/day, bounds: $[0.0, 500.0]$).
- `relative_humidity_pct` (float): 2-meter relative humidity (%, bounds: $[0.0, 100.0]$).
- `solar_radiation_mj` (float): All-sky surface downward shortwave radiation (MJ/m²/day, bounds: $[0.0, 45.0]$).
- `wind_speed_ms` (float): 2-meter wind speed (m/s, bounds: $[0.0, 100.0]$).

### 2.3 Soil Profile Record (`SoilRecord`)
- `plot_id` (str, optional): Target farm plot reference.
- `depth_cm` (float): Sampling depth ($[0.0, 200.0]$ cm).
- `ph` (float): Soil acidity level ($[3.0, 11.0]$).
- `moisture_pct` (float): Volumetric moisture content ($[0.0, 100.0]$ %).
- `nitrogen_mg_kg` (float, optional): Nitrogen concentration ($[0.0, 1000.0]$ mg/kg).
- `phosphorus_mg_kg` (float, optional): Available Phosphorus ($[0.0, 1000.0]$ mg/kg).
- `potassium_mg_kg` (float, optional): Available Potassium ($[0.0, 1000.0]$ mg/kg).
- `organic_matter_pct` (float, optional): Soil organic matter ($[0.0, 100.0]$ %).

### 2.4 Crop Yield Record (`CropYieldRecord`)
- `plot_id` (str): Target farm plot reference.
- `crop_type` (str): Plant crop species name (e.g., Tomato, Potato, Pepper).
- `harvest_year` (int): Harvest year ($[1900, 2100]$).
- `yield_kg_per_ha` (float): Yield metric in kg/ha ($[0.0, 50000.0]$).
- `area_hectares` (float): Plot area in hectares ($> 0.0$).

## 3. Existing Local Datasets & Artifacts

### 3.1 PlantVillage Crop Disease Dataset
- **Local Location:** `data/raw/PlantVillage/` and `data/processed/PlantVillage/`
- **Total Classes:** 15 crop disease / healthy categories across Pepper, Potato, and Tomato:
  1. `Pepper__bell___Bacterial_spot`
  2. `Pepper__bell___healthy`
  3. `Potato___Early_blight`
  4. `Potato___Late_blight`
  5. `Potato___healthy`
  6. `Tomato_Bacterial_spot`
  7. `Tomato_Early_blight`
  8. `Tomato_Late_blight`
  9. `Tomato_Leaf_Mold`
  10. `Tomato_Septoria_leaf_spot`
  11. `Tomato_Spider_mites_Two_spotted_spider_mite`
  12. `Tomato__Target_Spot`
  13. `Tomato__Tomato_mosaic_virus`
  14. `Tomato__Tomato_YellowLeaf__Curl_Virus`
  15. `Tomato_healthy`
- **File Counts:** 20,636 total raw files (20,635 images) vs. 20,633 total processed files (20,632 images).
- **Extreme Class Imbalance:**
  - Majority class: `Tomato__Tomato_YellowLeaf__Curl_Virus` (3,208 raw / 3,205 processed).
  - Minority class: `Potato___healthy` (152 raw / 152 processed).

### 3.2 Outlier Audit Report (`suspicious_outliers/outlier_report.csv`)
Generated via pre-trained feature extraction (e.g., ResNet/ImageNet embeddings) and IsolationForest density estimation:
- `image_path`: Full file system path to the audited image.
- `class_name`: Nominal ground-truth folder classification.
- `cosine_distance`: Cosine distance of sample embedding to class centroid.
- `mean_class_distance`: Mean embedding distance within nominal class.
- `iso_score`: Isolation Forest anomaly score (negative indicates higher anomaly probability).
- `top_imagenet_pred`: Top zero-shot ImageNet category prediction.
- `top_imagenet_prob`: Softmax probability of top zero-shot ImageNet category.
- `is_outlier`: Boolean flag indicating flagged outlier status.
- `outlier_reason`: Explanatory reason string (e.g. Non-leaf background, human finger/hand visible, fruit/object match).

## 4. Assignment External Data Sources: Scope & Boundaries

The project architecture identifies multiple candidate external data sources for multi-modal expansion in subsequent stages. Their role, protocol, schema, and current acquisition boundaries are detailed below:

| Source | Domain & Parameters | Ingestion Protocol | Epistemic Type | Scope & Hardware Boundaries |
| :--- | :--- | :--- | :--- | :--- |
| **NASA POWER** | Daily Agroclimatology (`T2M`, `PRECTOTCORR`, `RH2M`, `ALLSKY_SFC_SW_DWN`, `WS2M`) | REST API point query (`power.larc.nasa.gov`) | `external` | **Implemented in Step 4A.** Bounded to target agricultural regions and short date windows. |
| **SoilGrids (ISRIC)** | Global soil properties (pH, organic carbon, clay content, CEC at 0-30cm depths) | OGC WCS / REST API (`rest.isric.org`) | `external` | **Pending Stage 4 expansion.** Requires spatial coordinate bounding box; no global downloads. |
| **FAOSTAT** | National & regional annual crop yield statistics, fertilizer, trade | REST API / CSV dumps | `external` | Country-level macro baselines for yield benchmark comparisons. |
| **USDA NASS** | High-resolution field crop acreage and yield surveys | QuickStats API | `external` | Baseline validation data for crop yield regression models. |
| **Copernicus Sentinel-2** | Multi-spectral satellite surface reflectance (NDVI, NDRE, EVI, MSI) | Planetary Computer / Copernicus Open Access Hub | `external` | Cloud-masked optical imagery; restricted strictly to farm bounding boxes during pilot growing seasons. |
| **NASA Earthdata (MODIS/SMAP)** | Soil moisture anomalies, Land Surface Temperature (LST) | NASA Earthdata Cloud API | `external` | Coarse resolution ($9-36$ km) regional hydrology context. |
| **Plant Pathology 2020 (FGVC7)** | Field-condition apple/foliar disease photographs | Kaggle API / manual archive | `external` | Complex in-field background benchmarking to supplement laboratory-condition PlantVillage images. |
| **AgERA5 (ECMWF)** | High-resolution agricultural reanalysis weather data ($0.1^\circ$ grid) | Copernicus Climate Data Store (CDS API) | `external` | High-fidelity historical reanalysis for historical yield training; strictly clipped by polygon. |
| **Global Surface Water (JRC)** | Surface water occurrence, recurrence, seasonality | Google Earth Engine / JRC direct tiles | `external` | Flood risk and drainage assessment for digital twin scenario simulations. |
